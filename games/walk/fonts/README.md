# MuseJazzText.otf

The typeface of the chord symbols, the "marker" hand of a Real Book:
MuseJazz Text, by Torsten Hämmerle and Abraham Lee, as shipped with
MuseScore (`fonts/musejazz/` in the `musescore/MuseScore` repository,
commit 9140c5e4b7b5b48357b8d38dfebd0dd979653d21), unmodified.

It has the letters, the digits and the signs `naming` writes: ♭ ♮ ♯, ø
and °. It has no kerning, its source file having been lost (MuseScore
forum): awkward pairs will be adjusted by hand.
